📡 API Endpoints

RESTful API endpoints for programmatic access:

GET /api/cbp/states?year=2023

State-level business data (establishments, employees, payroll)

GET /api/cbp/counties/{state_fips}?year=2023

County-level business data for a specific state

GET /api/cbp/industries?year=2023

Industry breakdown by NAICS code

GET /api/cbp/trends

Employment trends over time

GET /api/zbp/zipcode/{zipcode}?year=2023

Business data for a specific ZIP code

GET /api/nes/states?year=2023

Self-employment data by state

GET /api/acs/states?year=2023

Demographics (population, income, housing)

GET /api/combined/state-profile/{state_fips}

Comprehensive state profile (all datasets)
